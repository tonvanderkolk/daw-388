# 0.34.0 LINK per paar Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tracks 1-2, 3-4, 5-6 and 7-8 can be linked as a stereo pair (fader, keys, channel, monitor and edits follow each other), a stereo import links its pair, and two small alignments in the MASTER columns.

**Architecture:** A new module `crates/ui/src/link.rs` holds the pure part: a `Linked` snapshot of what a pair shares and `link_from`, which turns one side into the other (PAN mirrored, input +1 or −1). `DawApp::sync_links` runs once per frame after the views: it compares each linked pair with last frame's snapshot and copies the side that changed, so no knob needs to know about linking. Editing follows through the selection: selecting a region also selects its counterpart on the partner.

**Tech Stack:** Rust 2024, egui/eframe 0.37, serde.

**Spec:** `docs/superpowers/specs/2026-11-04-link-en-bounce-setup-design.md` (part 1 and 2; Bounce Setup is 0.35.0, not in this plan).

**Conventions:**
- Toolchain: `export PATH="$(brew --prefix rustup)/bin:$PATH"` before any cargo command.
- UI text and code comments in English; CHANGELOG, ROADMAP, PROJECT.md in Dutch, no em or en dashes.
- **Do not commit.** Ton tests the build himself and says "commit en push". Each task ends with the checks, not a commit.
- Checks: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`.
- Pair numbering in code: pair `p` (0..4) is tracks `2p` and `2p+1` (0-based); `2p` is the left (odd-numbered) track.

//! LINK: two tracks of a pair (1-2, 3-4, 5-6, 7-8) as one stereo channel. What they share is
//! in [`Linked`]; [`link_from`] turns one side into the other.

use daw388_project::session::{ChannelEntry, MonitorEntry};

/// The settings a linked pair shares, as one track has them.
#[derive(Debug, Clone, Copy, PartialEq)]
pub(crate) struct Linked {
    pub fader_db: f32,
    pub pan: f32,
    pub mute: bool,
    pub input: Option<u16>,
    pub channel: ChannelEntry,
    pub monitor: MonitorEntry,
}

/// The pair a track belongs to (0 for tracks 1 and 2), and its partner.
pub(crate) fn pair_of(track: usize) -> usize {
    track / 2
}

pub(crate) fn partner(track: usize) -> usize {
    track ^ 1
}

/// The other side of a stereo pan: `-pan`, without a negative zero in `project.json`.
pub(crate) fn mirror(pan: f32) -> f32 {
    if pan == 0.0 { 0.0 } else { -pan }
}

/// What the partner of a track with `from` gets. `left` is whether `from` is the left (odd-
/// numbered) track. The input runs on (IN 1 gives IN 2, and back); without that input
/// (`input_channels` known and too few) the partner gets none.
pub(crate) fn link_from(from: Linked, left: bool, input_channels: u16) -> Linked {
    let input = from.input.and_then(|n| if left { n.checked_add(1) } else { n.checked_sub(1) }).filter(|&n| {
        n >= 1 && (input_channels == 0 || n <= input_channels)
    });
    Linked {
        pan: mirror(from.pan),
        input,
        monitor: MonitorEntry { pan: mirror(from.monitor.pan), ..from.monitor },
        ..from
    }
}

```rust
use super::*;

impl DawApp {
    fn linked(&self, track: usize) -> Linked {
        let t = &self.tracks[track];
        Linked { fader_db: t.fader_db, pan: t.pan, mute: t.mute, input: t.input, channel: t.channel, monitor: t.monitor }
    }

    fn input_channels(&self) -> u16 {
        self.output.as_ref().and_then(|o| o.input.as_ref()).map_or(0, |i| i.channels)
    }

    /// Give `to` what `from` has, as its partner, and tell the engine.
    fn copy_side(&mut self, from: usize, to: usize) {
        let l = link_from(self.linked(from), from % 2 == 0, self.input_channels());
        let t = &mut self.tracks[to];
        (t.fader_db, t.pan, t.mute, t.input, t.channel, t.monitor) = (l.fader_db, l.pan, l.mute, l.input, l.channel, l.monitor);
        if self.tracks[to].solo != self.tracks[from].solo {
            self.tracks[to].solo = self.tracks[from].solo;
            let solo = self.tracks[to].solo;
            self.engine_send(Command::SetSolo(to, solo));
        }
        if self.tracks[to].armed != self.tracks[from].armed {
            self.toggle_arm(to);
        }
        self.send_channel(to);
        self.send_monitor(to);
    }

    /// Once a frame, after the views: a linked pair where one side changed gets that change on
    /// the other side too.
    pub(crate) fn sync_links(&mut self) {
        let now: [Linked; TRACKS] = std::array::from_fn(|t| self.linked(t));
        if let Some(seen) = self.link_seen {
            for pair in 0..TRACKS / 2 {
                if !self.mixer.links[pair] {
                    continue;
                }
                let (l, r) = (2 * pair, 2 * pair + 1);
                let keys = |t: &TrackState| (t.solo, t.armed);
                let keys_differ = keys(&self.tracks[l]) != keys(&self.tracks[r]);
                // SOLO and REC are not in the snapshot: the key that was pressed says which side.
                let from = if now[l] != seen[l] {
                    Some(l)
                } else if now[r] != seen[r] {
                    Some(r)
                } else if keys_differ {
                    Some(self.link_touched.filter(|&t| t == r).unwrap_or(l))
                } else {
                    None
                };
                if let Some(from) = from {
                    self.copy_side(from, from ^ 1);
                    self.mark_dirty();
                }
            }
        }
        self.link_touched = None;
        self.link_seen = Some(std::array::from_fn(|t| self.linked(t)));
    }

    /// The LINK key of a pair. On: the right side takes the left's settings; two centred pans
    /// become left and right (in 388 mode also in MONITOR). Off: everything stays as it is.
    pub(crate) fn set_link(&mut self, pair: usize, on: bool) {
        self.mixer.links[pair] = on;
        let l = 2 * pair;
        if on {
            if self.tracks[l].pan == 0.0 {
                self.tracks[l].pan = -1.0;
            }
            if self.mixer.mode == Routing::Classic && self.tracks[l].monitor.pan == 0.0 {
                self.tracks[l].monitor.pan = -1.0;
            }
            self.copy_side(l, l + 1);
            self.send_channel(l);
            self.send_monitor(l);
        }
        self.link_seen = None;
        self.mark_dirty();
    }
}
```

In `link.rs` (`impl DawApp`):

```rust
    /// The region on the linked partner that starts where `index` on `track` starts and is as
    /// long: its other side.
    pub(crate) fn counterpart(&self, track: usize, index: usize) -> Option<(usize, usize)> {
        if !self.mixer.links[pair_of(track)] {
            return None;
        }
        let region = self.tracks[track].regions.get(index)?;
        let other = partner(track);
        let at = self.tracks[other]
            .regions
            .iter()
            .position(|r| (r.start - region.start).abs() < 1e-9 && (r.length - region.length).abs() < 1e-9)?;
        Some((other, at))
    }

    /// A move or copy by `track_delta` tracks: a selection on a linked pair only moves by whole
    /// pairs onto linked pairs; otherwise not between tracks at all.
    pub(crate) fn linked_delta(&self, tracks: &[usize], track_delta: isize) -> isize {
        let linked = |t: usize| self.mixer.links[pair_of(t)];
        if !tracks.iter().any(|&t| linked(t)) {
            return track_delta;
        }
        let fits = track_delta % 2 == 0
            && tracks.iter().all(|&t| {
                let to = t as isize + track_delta;
                (0..TRACKS as isize).contains(&to) && (!linked(t) || linked(to as usize))
            });
        if fits { track_delta } else { 0 }
    }
```
