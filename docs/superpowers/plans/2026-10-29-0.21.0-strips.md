# 0.21.0 Strips en master zoals de 388 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** De console krijgt de indeling van een echte 388:
- strips met vaste vlakken onder elkaar, op dezelfde hoogte in alle strips en gescheiden door dunne lijnen
- een master-sectie in twee kolommen
- een paneel EFFECTEN onder het transport

Spec: `docs/superpowers/specs/2026-10-29-fase8-strips-design.md`.

**Architecture:**
- De console-code (strip, PGM, MONITOR, master en effecten) verhuist eerst ongewijzigd uit `lib.rs` (ruim 4200 regels) naar een eigen module `crates/ui/src/console.rs`, een `impl DawApp`-blok zoals `drawer.rs`.
- Daarna komt er één bouwsteen `section`: een vlak met een vaste hoogte, een label en een lijn eronder. De vlakhoogtes zijn constanten, en een pure functie rekent uit waar de faders beginnen. Daardoor staan alle faders vanzelf op één lijn en kan het uitlijnen via het vorige beeld (`fader_row`) weg.
- `KeyCap` krijgt een variant met het label links van de toets, voor ASSIGN.

**Tech Stack:** Rust 2024, egui/eframe 0.37.

**Werkafspraken:** zoals in de plannen van 0.19.0 en 0.20.0:
- `export PATH="$(brew --prefix rustup)/bin:$PATH"`
- Niet committen tot Ton "commit en push" zegt.
- Na elke taak: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`.
- Code en commentaar in het Engels, UI-teksten in het Nederlands, de bekende schrijfregels.

```rust
/// Heights of the bands of a strip, in points, label included.
pub(crate) const BAND_TRACK: f32 = 58.0;
pub(crate) const BAND_INPUT: f32 = 78.0;
pub(crate) const BAND_EQ: f32 = 132.0;
pub(crate) const BAND_AUX: f32 = 84.0;
pub(crate) const BAND_ASSIGN: f32 = 104.0;
pub(crate) const BAND_PAN: f32 = 58.0;
pub(crate) const BAND_KEYS: f32 = 38.0;

/// Where the faders start below the top of the strips: the bands above them, ASSIGN only in the 388 routing.
pub(crate) fn fader_top(classic: bool) -> f32 {
    let assign = if classic { BAND_ASSIGN } else { 0.0 };
    BAND_TRACK + BAND_INPUT + BAND_EQ + BAND_AUX + assign + BAND_PAN + BAND_KEYS
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn the_faders_start_below_all_bands() {
        assert_eq!(fader_top(true), 552.0);
        assert_eq!(fader_top(false), 552.0 - BAND_ASSIGN, "no ASSIGN in the simple mode");
    }
}
```

De hoogtes zijn een eerste schatting; Step 3 kijkt of de inhoud past. Past de inhoud niet, verander dan de constante en de verwachte som in de test samen.

- [ ] **Step 2: `section`**

```rust
/// One band of the console: its label small at the top left, the content centred in exactly
/// `height` points (clipped if it would run over), and a thin line under it, as on the 388.
pub(crate) fn section<R>(ui: &mut Ui, label: &str, height: f32, add: impl FnOnce(&mut Ui) -> R) -> R {
    let width = ui.available_width();
    let (rect, _) = ui.allocate_exact_size(vec2(width, height), Sense::hover());
    let top = if label.is_empty() { 4.0 } else { 14.0 };
    let inner = Rect::from_min_max(rect.min + vec2(0.0, top), rect.max - vec2(0.0, 3.0));
    let mut child = ui.new_child(egui::UiBuilder::new().max_rect(inner).layout(Layout::top_down(Align::Center)));
    child.set_clip_rect(rect.intersect(ui.clip_rect()));
    if !label.is_empty() {
        ui.painter().text(rect.left_top() + vec2(3.0, 2.0), egui::Align2::LEFT_TOP, label, egui::FontId::proportional(9.0), palette::TEXT_DIM);
    }
    let result = add(&mut child);
    let line = palette::TEXT_DIM.gamma_multiply(0.35);
    ui.painter().line_segment([rect.left_bottom(), rect.right_bottom()], Stroke::new(1.0, line));
    result
}
```

Gebruik `egui::Rect` en `egui::Sense`; ze zijn er via `use super::*` als `lib.rs` ze importeert, anders met het volledige pad.
