# 0.11.0 Sends en masters Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per kanaal een AUX-send (PRE of POST) en een EFF-send, AUX- en EFF-masters naar vrije interface-uitgangen, een keuze STEREO/AUX/EFF voor de hoofduitgang, MONITOR/PHONES en een METER-schakelaar. In beide standen.

**Architecture:** `Channel::process` levert twee nieuwe aftakkingen: `aux` (PRE: na TRIM en voorversterker, voor EQ, fader en mute; POST: na fader en mute, voor PAN) en `eff` (na fader en mute). De engine sommeert ze per frame (alleen wat hoorbaar is, zoals de bussen), past de masters toe, schrijft AUX en EFF naar hun uitgangskanaal en kiest wat er op de hoofduitgang komt. PHONES schaalt de hoofduitgang; de klik komt daarna. De uitgangskanalen zijn app-voorkeuren; de rest staat in het project.

**Tech Stack:** Rust 2024, egui/eframe 0.37, serde, cpal (alleen het aantal uitgangskanalen doorgeven). Spec: `docs/superpowers/specs/2026-10-28-fase4-mixer-design.md` (Stereo, AUX en EFF; Testen, Sends), plus de besluiten hieronder.

**Werkafspraken:**
- cargo staat niet op PATH: begin elke shell met `export PATH="$(brew --prefix rustup)/bin:$PATH"`.
- Niet committen. Ton test eerst en zegt zelf "commit en push".
- Geen allocaties, locks of I/O in de audiothread.
- Code en commentaar in het Engels; Nederlandse UI-teksten en docs zonder komma voor "en", "of" en "noch" en zonder em dash.
- Na elke taak: `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings` en `cargo test --workspace` groen.

## Besluiten bovenop de spec

- **Sends in beide standen** (Ton, 28-10-2026). De eenvoudige strook krijgt dezelfde AUX-knop met PRE en EFF-knop.
- **EFFECT RTN wacht op fase 6.** Knoppen die niets doen verwarren; ze komen samen met de galm en de tape echo.
- **SOLO raakt de sends niet.** Een koptelefoonmix op AUX verandert niet als iemand achter de mixer een spoor solo zet. EFF volgt in fase 6 dezelfde regel; daar beslissen we of de EFFECT RTN meedoet met SOLO.
- **Sends dicht bij de start**: een nieuw kanaal en een kanaal uit een ouder project hebben AUX en EFF op -inf (opgeslagen als -60 dB, de onderkant van de knop).
- **Meeluisteren uit**: een live bron gaat ook niet naar AUX of EFF (zoals in de spec).

```rust
    #[test]
    fn aux_pre_ignores_eq_fader_and_mute_and_post_follows_the_fader_not_the_pan() {
        let mut eq = EQ_DEFAULTS;
        eq[1].gain_db = 15.0;
        let base = ChannelParams { source: Source::Line, aux: 0.5, eff: 0.25, fader: 0.5, pan: -1.0, eq, ..ChannelParams::default() };
        let mut pre = settled(ChannelParams { aux_pre: true, mute: true, ..base });
        let taps = pre.process(0.0, true);
        assert_eq!(taps.aux, 0.0);
        // DC through a peaking EQ is unchanged, so a constant shows what the send taps.
        let mut taps = pre.process(1.0, true);
        for _ in 0..100 {
            taps = pre.process(1.0, true);
        }
        assert!((taps.aux - 0.5).abs() < 1e-4, "PRE: TRIM only, then the send: {}", taps.aux);
        assert_eq!(taps.eff, 0.0, "EFF is after mute");

        let mut post = settled(ChannelParams { aux_pre: false, ..base });
        let mut taps = post.process(1.0, true);
        for _ in 0..100 {
            taps = post.process(1.0, true);
        }
        assert!((taps.aux - 0.25).abs() < 1e-3, "POST: fader 0.5 times send 0.5, PAN does not count: {}", taps.aux);
        assert!((taps.eff - 0.125).abs() < 1e-3, "EFF: fader 0.5 times send 0.25: {}", taps.eff);
    }
```

(`settled` laat de afvlakking uitlopen met stilte; de sends vloeien over net als de fader. Gebruik voor de constante een paar honderd samples zodat de EQ-toestand ook stabiel is.)

- [ ] **Step 3: Implementeer**

`ChannelParams` na `fader`/`pan`/`mute`:

```rust
    /// Linear AUX send; PRE takes it after TRIM and the preamp (before EQ, fader and mute),
    /// POST after fader and mute.
    pub aux: f32,
    pub aux_pre: bool,
    /// Linear EFF send, after fader and mute.
    pub eff: f32,
```

Standaard `aux: 0.0, aux_pre: false, eff: 0.0`. `Channel` krijgt `sends: [f32; 2]` (overgevloeide AUX en EFF), in `new` op `[0.0; 2]`. In `process` na de fader-afvlakking:

```rust
        smooth(&mut self.sends[0], self.params.aux);
        smooth(&mut self.sends[1], self.params.eff);
```

en aan het eind (de fader- en mutewaarde als scalar: `let fader = self.current[0].hypot(self.current[1]);`):

```rust
        let post = pre * fader;
        let aux = self.sends[0] * if self.params.aux_pre { shaped } else { post };
        let eff = self.sends[1] * post;
        Taps { pre, direct, post, aux, eff, left: pre * self.current[0], right: pre * self.current[1] }
```

`Taps` krijgt `aux` en `eff` met doc.

```rust
    #[test]
    fn aux_and_eff_go_to_their_own_outputs_through_their_masters() {
        let (mut handle, mut engine) = create(48_000);
        handle.send(Command::SetTrack(0, audio(vec![0.5; 100_000])));
        handle.send(Command::SetChannel(0, ChannelParams { aux: 1.0, aux_pre: true, eff: 0.5, ..ChannelParams::default() }));
        handle.send(Command::SetMixer(MixerParams { aux_master: 0.5, aux_out: Some(2), eff_out: Some(3), ..MixerParams::default() }));
        let mut scratch = vec![0.0; 4 * 20_000];
        engine.render(&mut scratch, 4);
        handle.play();
        let mut out = vec![0.0; 4 * 4];
        engine.render(&mut out, 4);
        assert!((out[4 * 3 + 2] - 0.25).abs() < 1e-4, "AUX: 0.5 times send 1 times master 0.5: {out:?}");
        assert!((out[4 * 3 + 3] - 0.25).abs() < 1e-4, "EFF: 0.5 times send 0.5 times master 1: {out:?}");
        assert_eq!(handle.take_send_peaks().map(|p| (p * 1e4).round()), [2500.0, 2500.0], "the METER switch shows them after the masters");
    }

    #[test]
    fn listen_puts_aux_on_the_main_output_and_phones_leaves_the_click_alone() {
        let (mut handle, mut engine) = create(48_000);
        handle.send(Command::SetTrack(0, audio(vec![0.5; 100_000])));
        handle.send(Command::SetChannel(0, ChannelParams { aux: 1.0, aux_pre: true, lr: true, ..ChannelParams::default() }));
        handle.send(Command::SetMixer(MixerParams { listen: Listen::Aux, phones: 0.5, ..MixerParams::default() }));
        settle(&mut engine);
        handle.play();
        let out = run(&mut engine, 4);
        assert!((out[6] - 0.25).abs() < 1e-4 && (out[7] - 0.25).abs() < 1e-4, "AUX in mono, times PHONES: {out:?}");
        // The click is added after PHONES, at its own volume: compare with PHONES at 1.
        // (Follow `the_click_sounds_when_recording_or_always_but_not_into_the_meters`: switch the
        // click on with SetClick and SetClickAlways, render a beat with phones 1.0 and with 0.5 on
        // silent tape, and check the click's peak is the same both times.)
    }

    #[test]
    fn a_live_source_without_software_monitoring_stays_off_the_sends() {
        let (mut handle, mut engine, mut tx, _recorder) = with_input();
        handle.send(Command::SetMonitoring(false));
        handle.send(Command::SetChannel(0, ChannelParams { source: Source::Line, input: Some(1), aux: 1.0, aux_pre: true, eff: 1.0, ..ChannelParams::default() }));
        handle.send(Command::SetMixer(MixerParams { listen: Listen::Aux, ..MixerParams::default() }));
        settle(&mut engine);
        feed(&mut tx, 0, 11);
        let out = run(&mut engine, 10);
        assert!(out.iter().all(|s| *s == 0.0), "{out:?}");
```

- [ ] **Step 3: Implementeer** in `render`:
  - per frame `let mut sends = [0.0f32; 2];` en per kanaal `sends[0] += taps.aux * audible; sends[1] += taps.eff * audible;`
  - `Engine` krijgt `send_gains: [f32; 2]` en `phones: f32` (overgevloeid, start op 1.0); na de kanaallus `smooth` naar `mixer.aux_master`, `mixer.eff_master` en `mixer.phones`.
  - `let aux = sends[0] * self.send_gains[0]; let eff = sends[1] * self.send_gains[1];` en hun pieken in `send_peaks`.
  - na MONO en de stereo-meters: `let (left, right) = match self.mixer.listen { Listen::Stereo => (left, right), Listen::Aux => (aux, aux), Listen::Eff => (eff, eff) };` dan maal `self.phones`, dan pas de klik erbij.
  - het frame: zoals nu, plus `if let Some(c) = self.mixer.aux_out && let Some(slot) = frame.get_mut(c) { *slot += aux; }` en hetzelfde voor EFF. Een kanaal 0 of 1 komt van de UI niet voor; `+=` voorkomt dat AUX en EFF op hetzelfde kanaal elkaar wissen.
  - `Shared` krijgt `send_peaks: [AtomicU32; 2]`, `EngineHandle::take_send_peaks() -> [f32; 2]`.
  - Pas de moduledoc en de doc van `SetMixer` aan.
