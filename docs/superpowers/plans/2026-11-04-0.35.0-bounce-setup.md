# 0.35.0 Bounce Setup Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One window sets the 388 routing for a live mix of some tracks onto one track or a pair (RMX, ASSIGN, PAN, L-R, DIRECT, REC, MONITOR and LINK), so nobody has to set the keys one by one.

**Architecture:** A new module `crates/ui/src/bounce.rs` holds the target type, the options, the window's draft and `DawApp::bounce_setup`, which only sets mixer state (no audio, no recording) and is tested on its own. `DawApp::bounce_notes` gives the warnings the window shows. The window (`bounce_window`) is opened from Edit, Bounce Setup... and from a key BOUNCE in the ROUTING band of the MASTER column.

**Tech Stack:** Rust 2024, egui/eframe 0.37.

**Spec:** `docs/superpowers/specs/2026-11-04-link-en-bounce-setup-design.md`, part 3.

**Conventions:**
- Toolchain: `export PATH="$(brew --prefix rustup)/bin:$PATH"` before any cargo command.
- UI text and code comments in English; CHANGELOG, ROADMAP, PROJECT.md in Dutch, no em or en dashes, no comma before en, of, noch.
- **Do not commit.** Ton tests the build himself and says "commit en push". Each task ends with the checks, not a commit.
- Checks: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`.
- Tracks are 0-based in code: track `t` is number `t + 1`. Pair `p` is tracks `2p` and `2p + 1`; ASSIGN key `k` (0..4) feeds buses `2k` and `2k + 1`; PAN −1 is the odd-numbered bus (left), +1 the even one (right).

**Choices where this plan fills in or departs from the spec (tell Ton):**
1. Simple mode: there is no question first. Going to 388 never asks (`set_routing(Routing::Classic)` only switches), so the window says "Apply switches the console to 388" and Apply does it.
2. Sources that are armed get REC FUNCTION off; otherwise they would record over themselves.
3. A mono target on a linked pair unlinks that pair, because arming one side of a linked pair would arm the other side too.
4. The window also warns when other channels stay on L-R: while one channel is on L-R, the MONITOR section does not reach STEREO, so you would not hear the target. Coming from SIMPLE, every other channel is on L-R.
5. SOURCES are check boxes in two columns with the track name, as in the Export window, not keys with the name below.
6. The spec's audio test ("a recording after Bounce Setup gives the same audio as the manual bounce test") becomes a test that the routing sent to the engine (`channel_params`) equals the routing of the engine's manual bounce test. The engine test already proves that routing records correctly.

```rust
//! Bounce Setup: the 388's routing for a live mix of some tracks onto one track or a pair, set
//! in one go. It only sets keys the console already has; recording stays REC and PLAY.

use super::*;

/// Where the bounce goes: one track (0-based) or a pair (0 for tracks 1 and 2).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum Target {
    Track(usize),
    Pair(usize),
}

impl Target {
    /// The tracks that record.
    pub(crate) fn tracks(self) -> Vec<usize> {
        match self {
            Target::Track(t) => vec![t],
            Target::Pair(p) => vec![2 * p, 2 * p + 1],
        }
    }

    /// The ASSIGN key that feeds the target's buses: 0 for 1-2, up to 3 for 7-8.
    pub(crate) fn assign(self) -> usize {
        match self {
            Target::Track(t) => t / 2,
            Target::Pair(p) => p,
        }
    }
}

/// The two check boxes of the window.
#[derive(Debug, Clone, Copy, PartialEq)]
pub(crate) struct BounceOptions {
    /// Mute the sources in MONITOR, so the mix is heard once, through the target.
    pub silence_sources: bool,
    /// Switch LINK on for a target pair.
    pub link_target: bool,
}

impl Default for BounceOptions {
    fn default() -> Self {
        Self { silence_sources: true, link_target: true }
    }
}

/// What the window holds while it is open.
#[derive(Debug, Clone, PartialEq, Default)]
pub(crate) struct BounceDraft {
    pub sources: [bool; TRACKS],
    pub target: Option<Target>,
    pub options: BounceOptions,
}

impl DawApp {
    /// Set the console for the bounce: 388 mode, the sources on RMX into the target's buses,
    /// the target armed and heard in MONITOR. Other tracks stay as they are.
    pub(crate) fn bounce_setup(&mut self, sources: [bool; TRACKS], target: Target, options: BounceOptions) {
        self.set_routing(Routing::Classic);
        let to = target.tracks();
        let key = target.assign();
        // A mono target on a linked pair: arming one side would arm the other.
        if let Target::Track(t) = target
            && self.mixer.links[link::pair_of(t)]
        {
            self.set_link(link::pair_of(t), false);
        }
        for t in (0..TRACKS).filter(|t| sources[*t] && !to.contains(t)) {
            let track = &mut self.tracks[t];
            track.channel.source = ChannelSource::Rmx;
            track.channel.assign = std::array::from_fn(|k| k == key);
            track.channel.lr = false;
            track.channel.direct = false;
            if let Target::Track(n) = target {
                // The odd-numbered bus (0-based even) is left.
                track.pan = if n.is_multiple_of(2) { -1.0 } else { 1.0 };
            }
            if options.silence_sources {
                track.monitor.mute = true;
            }
            if self.tracks[t].armed {
                self.toggle_arm(t);
            }
            self.send_channel(t);
            self.send_monitor(t);
        }
        for &t in &to {
            let track = &mut self.tracks[t];
            track.channel.assign = [false; 4];
            track.channel.lr = false;
            track.channel.direct = false;
            track.monitor.mute = false;
            track.monitor.pan = match target {
                Target::Pair(_) if t.is_multiple_of(2) => -1.0,
                Target::Pair(_) => 1.0,
                Target::Track(_) => 0.0,
            };
            if !self.tracks[t].armed {
                self.toggle_arm(t);
            }
            self.send_channel(t);
            self.send_monitor(t);
        }
        if let Target::Pair(p) = target
            && options.link_target
            && !self.mixer.links[p]
        {
            self.set_link(p, true);
        }
        // What was set here is the new state of every linked pair, not a change to copy over:
        // a linked source pair onto one track has both pans on the same side on purpose.
        self.link_seen = None;
        self.mark_dirty();
        self.status = "Bounce ready: press REC and PLAY".into();
    }
}
```

```rust
    /// What the window should say before Apply: audio on the target, a closed PGM master, the
    /// switch to 388, and channels that stay on L-R (then MONITOR does not reach STEREO).
    pub(crate) fn bounce_notes(&self, sources: &[bool; TRACKS], target: Target) -> Vec<String> {
        let to = target.tracks();
        let mut notes = Vec::new();
        for &t in &to {
            if !self.tracks[t].regions.is_empty() {
                notes.push(format!("Track {} has audio; recording replaces it where you record.", t + 1));
            }
            let (name, db) = if t.is_multiple_of(2) { ("ODD", self.mixer.odd_db) } else { ("EVEN", self.mixer.even_db) };
            if db <= MIN_DB {
                notes.push(format!("PGM MASTER {name} is closed: track {} records silence.", t + 1));
            }
        }
        let simple = self.mixer.mode == Routing::Simple;
        if simple {
            notes.push("Apply switches the console to 388.".to_string());
        }
        let on_lr: Vec<String> = (0..TRACKS)
            .filter(|t| !sources[*t] && !to.contains(t) && self.tracks[*t].channel.lr)
            .map(|t| (t + 1).to_string())
            .collect();
        if !on_lr.is_empty() {
            let (word, verb) = if on_lr.len() == 1 { ("Track", "stays") } else { ("Tracks", "stay") };
            notes.push(format!(
                "{word} {} {verb} on L-R: while a channel is on L-R, MONITOR does not reach STEREO and you won't hear the bounce.",
                on_lr.join(", ")
            ));
        }
        notes
    }
```

```rust
/// The sources after a click: a linked pair follows the side that changed, and the target's
/// tracks are never sources.
pub(crate) fn choose_sources(
    before: [bool; TRACKS],
    mut now: [bool; TRACKS],
    links: [bool; 4],
    target: Option<Target>,
) -> [bool; TRACKS] {
    for (pair, linked) in links.into_iter().enumerate() {
        let (l, r) = (2 * pair, 2 * pair + 1);
        if linked && now[l] != now[r] {
            let value = if now[l] != before[l] { now[l] } else { now[r] };
            (now[l], now[r]) = (value, value);
        }
    }
    for t in target.map(Target::tracks).unwrap_or_default() {
        now[t] = false;
    }
    now
}
```
