# 0.10.0 Eenvoudige stand Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Een eenvoudige stand naast de 388-stand: per spoor één strook (ingang, REC, fader is wat je hoort), standaard voor nieuwe projecten, met een schakelaar Eenvoudig | 388.

**Architecture:** De engine krijgt per kanaal `auto`: het kanaal speelt de band, en de ingang zodra zijn spoor naar de ingang luistert. Bij AUTO zit de DIRECT-aftakking voor de EQ en werken TRIM en de voorversterker alleen op de ingang. De eenvoudige stand is verder een vaste kanaalinstelling (AUTO, DIRECT, L-R) plus een eenvoudiger weergave in de UI. Het project bewaart `mixer.mode` en `channel.auto`; formaatversie blijft 2.

**Tech Stack:** Rust 2024, egui/eframe 0.37, serde. Spec: `docs/superpowers/specs/2026-10-28-eenvoudige-stand-design.md`.

**Werkafspraken (gelden voor elke taak):**
- cargo staat niet op PATH: begin elke shell met `export PATH="$(brew --prefix rustup)/bin:$PATH"`.
- Niet committen. Ton test eerst en zegt zelf "commit en push".
- Geen allocaties, locks of I/O in de audiothread.
- Code en commentaar in het Engels; Nederlandse UI-teksten en docs zonder komma voor "en", "of" en "noch" en zonder em dash.
- Na elke taak: `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings` en `cargo test --workspace` groen.

    /// Run one sample of the channel's source through it. `from_input`: the sample comes from
    /// the interface, not the tape.
    pub(crate) fn process(&mut self, sample: f32, from_input: bool) -> Taps {
        smooth(&mut self.trim, self.params.trim);
        let target = if self.params.mute { [0.0; 2] } else { pan_gains(self.params.fader, self.params.pan) };
        smooth(&mut self.current[0], target[0]);
        smooth(&mut self.current[1], target[1]);
        // With AUTO the tape skips TRIM and the preamp: they belong to the input.
        let gained = if from_input || !self.params.auto { sample * self.trim } else { sample };
        let shaped = if from_input && self.params.source == Source::Mic { preamp(gained) } else { gained };
        self.eq.target = self.params.eq;
        let pre = self.eq.process(shaped);
        let direct = match (self.params.auto, from_input) {
            (true, true) => shaped,
            (true, false) => 0.0,
            (false, _) => pre,
        };
        // Constant-power pan keeps left² + right² equal to the fader gain squared.
        let post = pre * self.current[0].hypot(self.current[1]);
        Taps { pre, direct, post, left: pre * self.current[0], right: pre * self.current[1] }
    }
```

Let op: MIC zonder AUTO komt altijd van de ingang, dus `from_input && source == Mic` verandert niets aan het gedrag van 0.9.0.

    /// Whether the mix is already as the simple mode sets it, so switching loses nothing.
    fn routing_is_simple(&self) -> bool {
        let channels = self.tracks.iter().all(|t| {
            let c = &t.channel;
            c.auto && c.direct && c.lr && c.assign == [false; 4] && c.source != ChannelSource::Rmx && t.monitor == MonitorEntry::default()
        });
        channels && self.mixer.odd_db == 0.0 && self.mixer.even_db == 0.0 && self.mixer.mon == MonSwitch::Cue
    }

    /// The Eenvoudig | 388 switch. To the simple mode asks first when that resets routing.
    fn set_routing(&mut self, mode: Routing) {
        if mode == self.mixer.mode {
            return;
        }
        match mode {
            Routing::Classic => {
                self.mixer.mode = Routing::Classic;
                self.mark_dirty();
            }
            Routing::Simple if self.routing_is_simple() => self.apply_simple(),
            Routing::Simple => self.confirm_simple = true,
        }
    }

    /// Every channel to the simple setting; fader, pan, mute, EQ, TRIM and input stay.
    fn apply_simple(&mut self) {
        self.confirm_simple = false;
        for track in &mut self.tracks {
            let channel = ChannelEntry::simple(track.channel.source);
            track.channel = ChannelEntry { trim_db: track.channel.trim_db, eq: track.channel.eq, ..channel };
            track.monitor = MonitorEntry::default();
        }
        self.mixer = MixerEntry { mode: Routing::Simple, mono: self.mixer.mono, ..MixerEntry::default() };
        self.send_mix();
        self.mark_dirty();
    }
```
