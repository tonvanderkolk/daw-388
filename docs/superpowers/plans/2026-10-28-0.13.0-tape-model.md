# 0.13.0 Tape-model Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Het karakter van de 388-band in de weergave: snelheid, tapesoort, saturatie, wow en flutter, ruis en crosstalk, met Clean / 388 en een venster Tape.

**Architecture:** De crate `daw388-tape` krijgt `TapeParams` en `TapeMachine` (acht sporen tegelijk, eigen tests, geen afhankelijkheden). De engine leest de band met een wow-verschuiving en laat `TapeMachine::process` de acht weergavewaarden bewerken voordat de kanalen ze zien. Opnames van de ingang raken het model niet. Project en UI volgen het patroon van de metronoom.

**Tech Stack:** Rust 2024, egui 0.37, serde. Spec: `docs/superpowers/specs/2026-10-28-fase6-tape-model-design.md`.

**Werkafspraken:**
- cargo: `export PATH="$(brew --prefix rustup)/bin:$PATH"`.
- Niet committen; Ton zegt zelf "commit en push" of "sync".
- Geen allocaties, locks of I/O in `process` of `render`.
- Code en commentaar in het Engels; Nederlandse teksten zonder komma voor "en", "of" en "noch" en zonder em dash.
- Na elke taak: `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` groen.

## Chunk 1: Het model

### Task 1: Filters

- [ ] `Biquad` (TDF-II, f64) met `peak(freq, gain_db, q, rate)` en `lowpass(freq, q, rate)` (RBJ), `process`. Test: een piekfilter van +1,5 dB geeft op zijn frequentie 1,5 dB binnen 0,1 dB; de laagdoorlaat dempt een sinus ver boven de afsnijfrequentie meer dan 10 dB.
- [ ] `Emphasis { k, last_in, last_out }` met `pre(x) = (1+k)x - k·x_prev` en `de(y) = (y + k·y_prev)/(1+k)`. Test: `de(pre(x))` geeft `x` terug binnen 1e-6 over een willekeurig signaal.

### Task 2: `TapeMachine`

```rust
pub enum Speed { Ips3_75, #[default] Ips7_5, Ips15 }
pub enum TapeKind { #[default] T456, T250, T911 }
pub struct TapeParams { pub on: bool, pub speed: Speed, pub kind: TapeKind, pub saturation: f32, pub wow_flutter: f32, pub noise: f32, pub crosstalk: f32 }
// Default: on false (Clean), 7½, 456, all 1.0.

pub struct TapeMachine { params, rate, tracks: [TrackState; 8], phases: [f32; 2], applied: (Speed, TapeKind) }
impl TapeMachine {
    pub fn new(sample_rate: u32) -> Self;
    pub fn set(&mut self, params: TapeParams);        // recomputes filters only when speed or kind change
    pub fn wow(&mut self) -> f64;                     // one frame: the position offset in samples (0 when off)
    pub fn process(&mut self, tracks: &mut [f32; 8], has_audio: [bool; 8], playing: bool);
}
```

- [ ] Tests eerst (zie de spec, Testen): Clean bit voor bit; 15 IPS meer hoog dan 3¾ op 12 kHz; saturatie lineair bij -30 dBFS (binnen 0,1 dB), afgeplat en begrensd bij een hard signaal, 250 meer dan 456; `wow()` binnen ±20 samples bij 200% en 0 bij 0% of Clean; ruis alleen als `playing && has_audio`, stil op 0%; crosstalk van spoor 2 rond -75 dB op 1 en 3 (binnen 2 dB, met saturatie, kleur en ruis uit), niets op 4.
- [ ] Implementatie volgens de spec: crosstalk uit een kopie van de invoer; saturatie `sat(u) = tanh(u + b) - tanh(b)` met b = 0,1, `y = sat(x·d)/d`, d = aansturing van de soort maal SATURATIE, alleen als d > 0, tussen pre- en de-emphasis (k = 0,5); daarna head bump, soortfilter en afrol; ruis: xorshift32 naar -1..1, door een eerste-orde laagdoorlaat (rond 8 kHz), geschaald naar het RMS-doel. `wow()`: twee fasen; verschuiving = rate × (Aw/(2π·0,5)·cos + Af/(2π·6)·cos) met Aw = 0,0006 en Af = 0,0004, maal snelheidsfactor (2,0 / 1,0 / 0,6) maal WOW & FLUTTER.
