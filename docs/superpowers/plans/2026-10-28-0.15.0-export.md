# 0.15.0 Export Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stereo bounce en losse sporen exporteren als WAV of AIFF, offline gerenderd. Spec: `docs/superpowers/specs/2026-10-28-fase7-export-design.md`.

**Architecture:** Bestanden schrijven en resamplen in `daw388-project` (`export.rs`, `aiff.rs` uitgebreid, `rubato`). De render in `daw388-ui` (`export.rs`): een `ExportJob` met kopieën van de clips en de mix-instellingen, die op een achtergrondthread een eigen `Engine` aanstuurt via de gewone commando's en `render` in blokken aanroept. Voortgang, annuleren en het resultaat via `Arc<Atomic*>` en een kanaal, zoals de laadjobs.

**Werkafspraken:** cargo-pad; niet committen; geen allocaties in de realtime-audiothread (de exportthread is geen realtime-thread en mag alloceren); Engelse code, Nederlandse teksten zonder komma voor "en", "of" en "noch" en zonder em dash; na elke taak fmt, clippy en tests groen.

## Chunk 1: Bestanden (`daw388-project`)

### Task 1: Resampler

- [ ] `rubato` in de workspace (`rubato = "0.16"` of de nieuwste versie die compileert; licentie MIT) en in `project`.
- [ ] `pub fn resample_hq(input: &[f32], from: u32, to: u32) -> Vec<f32>`: gelijk aan de invoer bij `from == to`; anders een sinc-resampler (`SincFixedIn`) over het hele signaal, uitvoerlengte `round(len × to / from)`.
- [ ] Test: een sinus van 1 kHz op 44,1 kHz naar 48 kHz heeft de juiste lengte en (geteld via nuldoorgangen) dezelfde frequentie binnen 1%.

### Task 2: Schrijvers

- [ ] `pub enum ExportFormat { Wav, Aiff }`, `pub enum BitDepth { Int16, Int24, Float32 }`.
- [ ] `pub fn write_audio(path, channels: &[Vec<f32>], rate, format, depth) -> Result<(), ProjectError>`: schrijft eerst naar `path.tmp` en hernoemt daarna. WAV via `hound` (16 en 24 bit integer, 32 bit float). AIFF zelf: `FORM`/`AIFF` met `COMM` (80-bit extended samplerate) en `SSND`, big-endian; float als `FORM`/`AIFC` met `FVER`, `COMM` met compressietype `fl32`, en `SSND`.
- [ ] Dither bij 16 bit: TPDF (som van twee uniforme waarden van ±0,5 LSB) uit een xorshift met vaste seed; daarna afronden en begrenzen.
- [ ] Tests: per formaat en diepte schrijven en teruglezen (WAV met `hound`, AIFF met de bestaande `load_audio`; stereo leest als mono gemiddeld, dus test AIFF met een mono-bestand op samplerate en lengte, en met stereo alleen op samplerate en lengte); dither: een constante van 0,4 LSB geeft bij 16 bit verschillende waarden, bij 24 bit één waarde.
- [ ] `pub fn export_name(project: &str, number: Option<usize>, clip: Option<&str>) -> String` (`Projectnaam_mix`, `Projectnaam_01_Kick`; onveilige tekens `_`) en `pub fn unused_path(dir, stem, extension) -> PathBuf` (`-2`, `-3`, ...). Tests.

## Chunk 2: Render (`daw388-ui/src/export.rs`)

### Task 3: `ExportJob`

```rust
pub(crate) struct ExportJob {
    pub rate: u32,
    pub clips: [Option<Arc<MonoClip>>; TRACKS],
    pub channels: [ChannelParams; TRACKS],
    pub monitors: [MonitorParams; TRACKS],
    pub mixer: MixerParams,
    pub master: f32,
    pub tape: TapeParams,
    pub meter: Meter,
    /// Start and end in seconds on the tape (end: the longest clip, or the CUE point).
    pub range: (f64, f64),
    pub stereo: Option<bool>,                 // Some(with tape)
    pub stems: Vec<(usize, StemKind)>,        // track index and processing
    pub from_zero: bool,
    pub dir: PathBuf, pub project: String, pub format: ExportFormat, pub depth: BitDepth,
}
pub(crate) enum StemKind { Mixed, TapeOnly, Dry }
pub(crate) struct Progress { pub done: AtomicU32 /* per mille */, pub cancel: AtomicBool }
pub(crate) fn run(job: ExportJob, progress: &Progress) -> Result<Vec<PathBuf>, String>
```

- [ ] `render(job, solo: Option<usize>, neutral: bool) -> [Vec<f32>; 2]`: maakt `daw388_engine::create(job.rate)`, stuurt `SetTrack` (de clip via `resample_hq` naar `job.rate`), `SetChannel`, `SetMonitor`, `SetMixer`, `SetMaster`, `SetTape`, `SetMeter`, eventueel `SetSolo`, `Locate(start)` en `Play`; rendert in blokken van 4096 frames tot het einde van het bereik, daarna de staart tot 0,5 s onder -90 dBFS (hooguit 10 s); kijkt per blok naar `cancel` en werkt `done` bij. `neutral` (alleen tape): elk kanaal RMX, EQ vlak, fader 1, pan hard links, L-R aan, sends dicht, mixer standaard, master 1; de stem is dan het linkerkanaal.
- [ ] Droog: de clip via `resample_hq`, uitgesneden op het bereik, zonder engine.
- [ ] `from_zero` uit: voeg stilte toe van 0 tot het begin van het bereik.
- [ ] Bij annuleren of een fout: de al geschreven bestanden van deze job verwijderen.
- [ ] Tests (in `export.rs`):
  - een bounce is gelijk aan wat een tweede engine met dezelfde commando's live geeft
  - een droge stem bij gelijke samplerate is de clip bit voor bit
  - de som van de stems "met mixer" is de bounce binnen 1e-4 (tape Clean, echo-feedback 0)
  - het bereik nul tot CUE geeft de juiste lengte plus een staart die stopt na stilte
  - annuleren laat geen bestanden achter
